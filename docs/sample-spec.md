## Acceptance criteria

- [ ] Given the list is filtered to status paid, when the user exports, then the CSV contains only the paid invoices that match the filters
- [ ] Given an invoice of 123450 cents, when it is exported, then the amount column reads $1,234.50
- [ ] Given invoices exist, when the user clicks Export on the invoices page, then a CSV file downloads with a header row and one row per invoice

### Edge cases raised by fewer lenses

- [ ] Given an export on 2026-11-21, when the file downloads, then it is named invoices-2026-11-21.csv (A)
- [ ] Given no invoices exist, when the user exports, then the CSV contains only the header row (C)
- [ ] Given a customer name starts with =, when the user exports, then the cell is prefixed with a single quote so Excel does not run it as a formula (C)
- [ ] Given 100,000 invoices, when the export runs, then rows are streamed in batches of 1,000 and memory stays flat (D)
- [ ] Given an export is in progress, when the user looks at the Export button, then it is disabled and shows a spinner (E)
